# CloseUp Photo Viewer

Extremely fast image viewer for Windows with built-in AI enhancement.

CloseUp is built for everyday work with large photo collections: photos open
instantly, navigation is smooth, and one click is enough to enhance or
upscale an image.

**Everything runs locally on your computer.** No ads, no online accounts,
no data collection — your files never leave your machine. All AI features
work fully offline.

## Features

- **Instant viewing** — folders with thousands of photos open without
  delays; frequently viewed images stay in a smart cache.
- **Smooth navigation** — the mouse wheel flips through photos, and a mini
  filmstrip at the bottom of the screen lets you jump to any image.
- **Effects Studio** — a strip of one-click enhancement variants for every
  photo; compare them side by side and save the best result next to the
  original.
- **AI upscaling** — carefully increase image resolution up to 4× without
  losing sharpness; ideal for crops and low-resolution shots.
- **Universal tool** — equally good for family archives, product shots,
  wallpapers, and art references.
- Light and dark themes, full-screen mode, and it can replace your default
  Windows image viewer.

## Download

The latest installer is published on the [Releases](releases) page — download
`CloseUp-Setup-<version>.exe` and run it. Installation is per-user: no
administrator rights are required. The `.sha256` file next to the installer
holds its checksum.

Updates are built in: **Settings → Updates → Check…** compares your copy with
the latest release and installs the update in one click.

**System requirements:** Windows 10 or newer. No internet connection is
required after installation; the only network feature is an optional
once-a-day update check (a single version request to GitHub) that can be
turned off in Settings.

Every feature is free to try: AI results carry a subtle demo watermark until
you activate a purchased license key in **Settings → License**.
